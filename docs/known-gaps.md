# Известные пробелы ядра

Список составлен по итогам ревью ядра спуска. Ничего из перечисленного не мешает
ядру работать, но каждый пункт стоит закрыть в подходящем месте, а не забыть.

## Ждут интерфейса

**Порты синхронные.** Чтение и запись объявлены обычными функциями, без отмены и
без сообщений о ходе работы. Как только адаптеры уедут в фоновый поток, сигнатуры
придётся сделать асинхронными: через границу потока синхронных вызовов не бывает.
Отсюда же два следствия: отказ «отменено» объявлен, но недостижим, а отказ по
нехватке памяти не представим вовсе, хотя оба нужны по замыслу.

**Дескриптор документа уникален только внутри одного экземпляра приложения.**
Происхождение помечается счётчиком, поэтому пересозданный фоновый поток примет
дескриптор от предыдущего и молча отдаст другой документ. Лечится случайным
идентификатором вместо счётчика, но проверить это можно только там, где
пересоздание действительно происходит.

**Метка группы у отказа по отрицательному вылету указывает на лист, а не на
полосы.** Интерфейс подсвечивает по этой метке ту группу параметров, где ошибка;
вылет живёт в группе полос. Правится вместе с самой группировкой контролов.

## Мелкий долг

- Полностью отсутствующий формат листа в исходнике даёт запасной размер, который
  расходится с тем, что подставляет движок. Случай встречается только на битых
  файлах, падения нет, есть смещение.
- Дырявая ссылка в содержимом полосы даёт пустую полосу вместо отказа. Это цена
  требования не ронять весь экспорт из-за одной пустой страницы в книге.
- Проверяется конечность ширины и высоты обрезного формата, но не его начала.
- У неполного листа внешняя линия реза со стороны пустых ячеек остаётся без
  меток: метки реза намеренно не рисуются вокруг пустоты.
- Метки реза не смотрят на соседние ячейки. При нулевом зазоре и плотной посадке
  плечо может лечь вдоль линии реза соседней полосы. Пока лечится тем, что зазор
  задаёт человек.

## Что теряется при спуске и это нормально

Аннотации, ссылки, поля форм, слои и разметка доступности в готовый спуск не
переносятся. Для спуска это ожидаемо, но стоит сказать вслух, чтобы не считали
ошибкой. Группа прозрачности переносится: без неё уезжает цвет.
